# Touched Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `Touched` and `TouchEnded` on every PhysicsBase, each passing a read-only `TouchObject` (Time, Instance, Point, Normal, RelativeVelocity), for collisions and for trigger zones (CanCollide-off bodies).

**Architecture:** A new `LuaSlot::Kind::TouchObject` carries a `TouchRecord` through the existing instance-event path (`DataModel::fire_event`) to a Luau userdata. CanCollide-off shapes become Box3D sensors. PhysicsWorld tracks touching shape pairs (from Box3D contact and sensor events) per body pair, enables contact events only on listened bodies, saves pre-step velocities while anyone listens, and fires the events after each step.

**Tech Stack:** C++17 (MSVC 14.23, /W4), Box3D (contact events, sensors, `b3Contact_GetData`, `b3Shape_GetClosestPoint`), Luau bindings, Catch2 sandbox.

**Spec:** `docs/superpowers/specs/2026-10-11-touched-design.md`

## Global Constraints

- Signals: `Touched(touch: TouchObject)`, `TouchEnded(touch: TouchObject)` on PhysicsBase (lua_event).
- TouchObject fields, verbatim: `Time`, `Instance`, `Point`, `Normal`, `RelativeVelocity`. Read-only; `typeof` is `"TouchObject"`.
- `Normal` points away from the receiving body. Trigger overlaps: `Normal` is (0, 0, 0), `Point` is the other body's position.
- `RelativeVelocity` = other's point velocity minus this body's, from before the step (begin); at the parting step (end). Terrain's velocity is zero.
- Fire once per body pair on 0→1 touching shape pairs, once on →0. Not every frame. Only while running; Stop clears pairs and fires nothing.
- Contact events only on listened bodies (a connected Touched or TouchEnded). No CanTouch.
- Build: `MSYS_NO_PATHCONV=1 cmake --build build --config Release --target <t> -- /m /v:minimal`. Python edits keep the file's line endings (`newline=''`).

## Review Focus

1. A shape remade while touching (a Brush face edit, a Size write, a CanCollide flip, a NoCollisionConstraint change) must not fire TouchEnded then Touched for a pair that kept touching.
2. A body destroyed or moved out of Workspace while touching: the other listened body gets exactly one TouchEnded.
3. A compound (welded) body: Box3D reports the compound's shapes; each must map to its member's PhysicsBase id (shape user data), never the root's.
4. A Touched handler that destroys or moves either body: the next step must not use stale shape ids.
5. Connecting Touched mid-contact must not fire for the existing contact, and must enable events for later contacts without remaking shapes.

## Decisions taken here (spec refinements)

- TouchObject is a userdata like InputObject and RaycastResult (spec: "frozen table"); the spec's section 1 is updated in Task 1.
- `Instance` reads nil when the other body was destroyed (a destroyed instance is freed in play); it is given when the other only left Workspace. Spec updated in Task 1.
- A pair whose touching count drops to 0 because PhysicsWorld itself removed shapes (a remake, a destroy) is held as pending; at the end of the next step it fires TouchEnded only if it has not touched again.

```cpp
bool DataModel::event_listened(InstanceId id, std::string_view name) const {
    const std::uint32_t index = id_slot(id);
    if (id == 0 || slot(id) == nullptr || index >= state_->bags.size() || !state_->bags[index] ||
        state_->bags[index]->owner != id) {
        return false;
    }
    for (const std::unique_ptr<InstanceSignals::Event>& event : state_->bags[index]->events) {
        if (event->name == name) {
            return event->signal.bound() && event->signal.listeners_ > 0;
        }
    }
    return false;
}
```

```cpp
int ScriptBindings::touch_object_index(lua_State* state) {
    const auto* record = static_cast<const TouchRecord*>(luaL_checkudata(state, 1, kTouchObjectMeta));
    const char* key = luaL_checkstring(state, 2);
    const std::string_view name = key != nullptr ? key : "";
    if (name == "Time") {
        lua_pushnumber(state, record->time);
    } else if (name == "Instance") {
        ScriptRuntime* runtime = runtime_from(state);
        if (runtime != nullptr && runtime->game_ != nullptr && runtime->game_->instance(record->instance) != nullptr) {
            runtime->push_instance(state, record->instance);
        } else {
            lua_pushnil(state);
        }
    } else if (name == "Point") {
        lua_pushvector(state, record->point.x, record->point.y, record->point.z);
    } else if (name == "Normal") {
        lua_pushvector(state, record->normal.x, record->normal.y, record->normal.z);
    } else if (name == "RelativeVelocity") {
        lua_pushvector(state, record->relative_velocity.x, record->relative_velocity.y, record->relative_velocity.z);
    } else {
        luaL_error(state, "%s is not a valid member of TouchObject", key != nullptr ? key : "");
    }
    return 1;
}

int ScriptBindings::touch_object_newindex(lua_State* state) {
    luaL_checkudata(state, 1, kTouchObjectMeta);
    luaL_error(state, "%s cannot be assigned to", luaL_checkstring(state, 2));
}

int ScriptBindings::touch_object_tostring(lua_State* state) {
    luaL_checkudata(state, 1, kTouchObjectMeta);
    lua_pushstring(state, "TouchObject");
    return 1;
}
```

```cpp
namespace {

struct Heard {
    engine_core::InstanceId on = 0;
    bool ended = false;
    engine_core::TouchRecord touch;
};

// Connects both signals of id; what fires lands in out.
void listen(engine_core::DataModel& game, engine_core::InstanceId id, std::vector<Heard>& out) {
    for (const char* name : {"Touched", "TouchEnded"}) {
        const bool ended = std::string(name) == "TouchEnded";
        game.event_signal(id, name).connect([&game, &out, id, ended](engine_core::InstanceId, engine_core::Field) {
            const engine_core::EventArgs* args = game.events().current_args();
            REQUIRE(args != nullptr);
            REQUIRE(args->size() == 1);
            out.push_back(Heard{id, ended, (*args)[0].touch});
        });
    }
}

std::size_t count(const std::vector<Heard>& heard, engine_core::InstanceId on, bool ended) {
    std::size_t n = 0;
    for (const Heard& h : heard) {
        n += h.on == on && h.ended == ended ? 1 : 0;
    }
    return n;
}

}  // namespace

TEST_CASE("T4 a box landing on a floor fires Touched once on each listener, with a TouchObject",
          "[touch][physics]") {

    PhysicsObject& floor = rig.floor();
    PhysicsObject& box = rig.body(at(0.f, 3.f, 0.f), Vec3{1.f, 1.f, 1.f}, false);
    std::vector<Heard> heard;
    listen(rig.game, box.id(), heard);
    listen(rig.game, floor.id(), heard);
    rig.play();
    rig.seconds(3.0);
    REQUIRE(count(heard, box.id(), false) == 1);
    REQUIRE(count(heard, floor.id(), false) == 1);
    REQUIRE(count(heard, box.id(), true) == 0);
    for (const Heard& h : heard) {
        const bool on_box = h.on == box.id();
        REQUIRE(h.touch.instance == (on_box ? floor.id() : box.id()));
        REQUIRE(near(h.touch.point.y, 0.f, 0.1f));
        REQUIRE(near(h.touch.normal.y, on_box ? -1.f : 1.f, 1e-3f));
        // The other's velocity relative to this one: the box was falling at about 7 units/s.
        REQUIRE(on_box ? h.touch.relative_velocity.y > 5.f : h.touch.relative_velocity.y < -5.f);
```

```cpp
    // Touching (Touched / TouchEnded, docs/superpowers/specs/2026-10-11-touched-design.md):
    // each touching shape pair (b3StoreShapeId keys, lower first) with its
    // two instances; per instance pair (pair_key) how many shape pairs touch
    // and the last TouchObject facts known; the pairs PhysicsWorld itself let
    // go of this step (pending ends); the seconds since Play; and, while
    // anyone listens, each body's velocities from before the step.
    struct ShapeTouch {
        InstanceId a = 0;
        InstanceId b = 0;
        bool sensor = false;
    };
    struct PairTouch {
        int count = 0;
        bool pending_end = false;
        Vec3 point{};
        Vec3 normal_from_low{};  // away from the lower id
        Vec3 velocity_of_high_from_low{};
    };
    struct Motion { b3Vec3 linear{}; b3Vec3 angular{}; b3Pos center{}; };
    std::unordered_map<std::uint64_t, ShapeTouch> shape_touches;      // key: two shape keys, hashed
    std::unordered_map<std::uint64_t, PairTouch> pair_touches;         // key: pair_key(a, b)
    std::unordered_map<std::uint64_t, Motion> before_step;             // key: b3StoreBodyId
    double play_seconds = 0.0;
    std::size_t listened = 0;
```

Shape-pair key: `std::hash` combine of the two `b3StoreShapeId` values ordered (`low * 1000003 ^ high`), with the two kept in the value for collision safety (store `std::uint64_t sa, sb` in ShapeTouch and compare on lookup; on a hash clash, linear-probe by `+1`).

Per sync (`sync`, after reconcile): for each body record, `listened_now = running && (game.event_listened(id, "Touched") || game.event_listened(id, "TouchEnded"))`; when it differs from `record.listened`, `b3Shape_EnableContactEvents(shape, listened_now)` for its shapes; count listeners into `listened`. Shape builders set `def.enableContactEvents = record.listened`. Not running: clear `shape_touches`, `pair_touches`, `play_seconds = 0`.

Before `b3World_Step` (in `simulate`), when `listened > 0`: fill `before_step` for every awake dynamic or kinematic record body (`b3Body_GetLinearVelocity`, `b3Body_GetAngularVelocity`, `b3Body_GetWorldCenter`).

After the step (`play_seconds += dt`):

1. Contact begin events: for each, `b3Contact_IsValid(contactId)` then `b3Contact_GetData`; instances from `b3Shape_GetUserData` of shapeIdA/B; average every manifold's points (`b3Body_GetWorldCenter(bodyA) + anchorA`), normal = first manifold's normal (A to B); relative velocity = point velocity of B minus A, from `before_step` (or current when absent; Terrain zero). Record the shape pair; `pair.count++`; on 0→1 (and not `pending_end`), fire Touched on each listened side; a `pending_end` pair returning to 1 clears `pending_end` and fires nothing.
2. Sensor begin events: the same, `sensor = true`, point = the other body's position per side, normal zero.
3. Contact and sensor end events: shapes no longer valid are skipped (already settled by `forget_shapes`, below). Else find the shape pair, erase it, `pair.count--`; on 1→0, fire TouchEnded on each listened side with `b3Shape_GetClosestPoint` (closest point on A to B's center, then on B to that; Point = midpoint, Normal = the gap direction; zero gap: the last known normal) and current point velocities.
4. Pending ends left from `forget_shapes` that did not return this step: fire TouchEnded from their last known facts, erase.

`forget_shapes(const Body& record)`, called from `drop_shape` before the shapes go: every shape pair naming one of them is erased and its `pair.count--`; a count reaching 0 becomes `pending_end`.

Firing: `game.fire_event(id, "Touched" | "TouchEnded", {slot})` only for ids alive, in Workspace, and listened; the slot's TouchRecord is built per side (normal and relative velocity negated for the higher id).

Test accessor `contact_events_enabled(id)`: every shape `b3Shape_AreContactEventsEnabled`.

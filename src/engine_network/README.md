# engine_network

`engine_network` replicates a server's instance tree to its clients over `anarchy_network`. Spec: `docs/superpowers/specs/2026-10-13-server-client-design.md`.

Bottom up: `ByteBuffer` (`ByteWriter` and `ByteReader`: little-endian values, varints, strings, never reading past the end), `JsonWire` (a property value as a save would write it, in binary; a number takes four bytes when a float holds it exactly and eight otherwise, so every value arrives exactly), `TreeCodec` (the op stream: `StringTable`, `OpWriter`, `read_ops`; codec version 2, named in every snapshot part's header and every Changes message). `Replicator` (what clients may see, and the join snapshot: the filtered tree as one op stream, zstd-compressed, cut into parts) and `ReplicaApplier` (reassembles a snapshot and applies ops through the ordinary setters, counting refused ones as skipped; a Destroy frees the netid of everything it takes). `Replicator::end_tick` turns each tick's journal into one Changes message. `Sessions` (`ServerSession`, `ClientSession`) wire an `anarchy_network` Endpoint to the tree: the server gives each client a Connection, its snapshot at the end of the tick it connects, and every later tick's changes behind it, one shared buffer for every client, dropping a client whose queue makes no progress for 30 s or grows past 256 MB ("Your connection could not keep up"); the client sets the Client role and starts play while empty, builds the world from the snapshot, and when the connection ends stops play it started, puts back the role it replaced, and says why in words for a player. A script that destroys a client's Connection removes that client ("Removed by the server"), and a closing server tells every client at once ("The server closed"). A connect the endpoint refuses leaves the client Disconnected ("Could not connect to the server"). `ClientSession::status()` copies the state and reason under a mutex for a thread other than the simulation's, such as a window's overlay. A client session runs in one of two modes (`ClientMode`): `FromEmpty` is `--connect` as above, and `Swap` is a script's join, where the playing standalone world stays untouched until the whole snapshot is in; then `ReplicaApplier::before_snapshot` runs `swap_for_client` and the world becomes a Client. A Swap connection that ends never stops play, and puts the role back only if the swap ran. `ClientSession::on_state` tells its owner, on the simulation thread, each time the state or reason changes. `ClientJoinHost` is a client program's `engine_core::IJoinHost`: `join` resolves the address on a thread of its own and hands the answer to a PreAnimation job on the thread stepping the world, dropping it when a Leave, a second Join or the host's end came first; it then connects a Swap session and reports Joined and Left through `Connections`. `connect_from_empty` is `--connect` through the same host, and `end_silently` (Studio Stop) ends any connection without Left. A session that ends inside its own callback is unhooked at once and destroyed at the next tick. `ClientWorld` (`clear_for_client`) empties a client's world down to its services, each back at its defaults, before it connects, so the snapshot builds the place into nothing else (a snapshot carries only the service values that differ from the defaults). `ProjectIdentity` (`project_identity`) is the `GameIdentity` a project presents, refusing a missing or all-zero gameId and an unreadable resources folder with a reason for a person. A session's now is `engine_core::Engine::network_now()`, the clock the engine pumps it with. `Sessions.hpp` lists the rules a session's owner keeps.

Nothing in the engine packages includes this library: `Engine` reaches a session only through `engine_core::INetworkPump`.

Tests: `sandbox/replication_*_tests.cpp`, tag `[replication]`; `sandbox/join_host_tests.cpp`, tag `[join]`.
